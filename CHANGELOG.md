# Changelog

Все заметные изменения Houdini Collector фиксируются в этом файле.

## [0.3.1] — 2026-08-24

### Добавлено

- режимы Selected Branches, Whole Scene, Selected ROPs, Project Only и Report Only;
- Asset Inspector с поиском, фильтрами и цветовой навигацией;
- отдельные столбцы Node и Parameter, переход к ноде и открытие файла в Explorer;
- ручное управление Asset-группами;
- сохранение состояния Scan;
- Incremental Update существующего коллекта;
- встроенные и пользовательские presets;
- tooltip-подсказки и настраиваемые столбцы;
- поиск и безопасный Relink потерянных файлов.

### Улучшено

- модели и однозначно связанные текстуры группируются без лишней вложенности;
- из Megascans-папок копируются только реально используемые файлы;
- HDRI, материалы, модели, кэши и Redshift Proxy раскладываются по понятной структуре;
- HDA/OTL Redshift и Maxon исключаются из коллекта.

### Совместимость

- основная тестовая версия: Houdini 21.0.671;
- Redshift;
- Karma/MaterialX;
- PySide2 с fallback для PySide6.
