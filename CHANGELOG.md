# Changelog

Все заметные изменения Houdini Collector фиксируются в этом файле.

## [0.3.2] — 2026-09-07

### Исправлено

- Одна исходная текстура, используемая несколькими материалами, теперь получает один Destination и копируется один раз.
- Папки обычных наборов текстур определяются исходной папкой; группировка строк по материалам сохраняется.
- Общие UDIM и последовательности сохраняют токены и единую папку, включая пересекающиеся наборы и отдельные тайлы/кадры.
- Одноимённые папки разных источников разделяются без смешивания файлов; порядок строк не влияет на назначение путей.
- Заголовок окна и версия в manifest берутся из общего `__version__`.
- Сохранены ручное переименование ассетов моделей, расположение Megascans и копирование при отключённой повторной строке.

### Проверки и обновление

- Добавлены регрессионные тесты повторных текстур, UDIM, последовательностей и Incremental Update.
- Проверки выполнены в Python и hython Houdini 21.0.671, включая реальные параметры Houdini; рендер Redshift не проверялся.
- После обновления нужны перезапуск Houdini и новый Scan. Существующие дубли автоматически не удаляются.

## [0.3.1] — 2026-08-24

### Добавлено

- режимы Selected Branches, Whole Scene, Selected ROPs, Project Only и Report Only;
- Asset Inspector с поиском, фильтрами и цветовой навигацией;
- отдельные столбцы Node и Parameter, переход к ноде и открытие файла в Explorer;
- ручное управление Asset-группами;
- сохранение состояния Scan;
- Incremental Update существующего коллекта;
- встроенные и пользовательские presets;
- tooltip-подсказки и настраиваемые столбцы;
- поиск и безопасный Relink потерянных файлов.

### Улучшено

- модели и однозначно связанные текстуры группируются без лишней вложенности;
- из Megascans-папок копируются только реально используемые файлы;
- HDRI, материалы, модели, кэши и Redshift Proxy раскладываются по понятной структуре;
- HDA/OTL Redshift и Maxon исключаются из коллекта.

### Совместимость

- основная тестовая версия: Houdini 21.0.671;
- Redshift;
- Karma/MaterialX;
- PySide2 с fallback для PySide6.
