# Houdini Collector 0.3.2

Исправлено дублирование текстур при использовании одного набора в нескольких материалах. Все ссылки на один исходный файл получают общий Destination, файл копируется один раз. Строки Asset Inspector остаются сгруппированными по материалам.

## Изменения

- Обычные наборы текстур собираются в `tex/mats/<source_folder>/`.
- Сохраняются UDIM, последовательности, пересекающиеся наборы и ссылки на отдельный кадр или тайл.
- Одинаковые имена файлов из разных источников не смешиваются; коллизии папок разделяются через `source_<hash>`.
- Сохранены расположение Megascans, однозначно принадлежащие моделям текстуры и ручное переименование ассетов моделей.
- Отключение одной повторной строки не мешает сбору остальных включённых ссылок.
- Заголовок окна и manifest показывают единую версию пакета.

## Обновление

1. Скачайте `HoudiniCollector_0.3.2_H21.zip` из Assets.
2. Сохраните резервную копию установленного пакета.
3. Скопируйте папки `packages` и `houdini_collector` из архива в `$HOUDINI_USER_PREF_DIR`.
4. Перезапустите Houdini, откройте Collector и выполните новый Scan.

Первую сборку после обновления сделайте в новую папку. Дубли из старых сборок не удаляются автоматически. При Incremental Update файлы прежней структуры могут остаться на диске.

## Проверка и статус

Public beta для Houdini 21.0.671 / Python 3.11. Проверены файловое копирование, перепривязка реальных параметров Houdini и регрессионные тесты предыдущей версии. Тесты hython выполнены без сторонних packages; рендер Redshift не проверялся.

Текстурные последовательности из нескольких разных исходных папок отклоняются с сообщением об ошибке: текущий коллектор не может безопасно выразить их одним шаблоном назначения.

Подробные инструкции и ограничения — в README.md.
